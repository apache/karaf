=== GitHub Contributions

Contributions to Apache Karaf are welcome via GitHub pull requests!

==== Introduction

The official Apache Karaf Git repository is hosted on GitHub: https://github.com/apache/karaf

==== Suggested Workflow

. Fork the https://github.com/apache/karaf[apache/karaf] repository on GitHub.
. Clone your fork locally and create a dedicated feature or bugfix branch based on `main`:
+
----
git clone https://github.com/<your-username>/karaf.git
cd karaf
git remote add upstream https://github.com/apache/karaf.git
git fetch upstream
git checkout -b my-branch upstream/main
----
. Implement your changes, add appropriate unit or integration tests, and verify the build:
+
----
mvn clean test
----
. Open a pull request against the `main` branch of `apache/karaf` on GitHub (and reference any related https://github.com/apache/karaf/issues[GitHub Issue]).
. Apache Karaf committers will review and discuss your pull request on GitHub, and merge it once approved and CI checks pass.
